# Publicación y visibilidad autorizadas

El repositorio de destino es [Anaa-K03/agentes](https://github.com/Anaa-K03/agentes). La usuaria suministró este enlace y autorizó expresamente proceder aunque sea público. Esa instrucción sustituye la preferencia inicial de nombre y privacidad. No se cambió visibilidad, se crearon credenciales ni se invitó a colaboradores.

Antes de la carga se verificaron cuenta, permisos de escritura y repositorio vacío mediante el conector GitHub. El contenido preparado para publicar es: roles, skills, guías, consultas y plantillas, junto al ZIP de entrada ya inspeccionado para trazabilidad. No se suben los PDF, sus extracciones completas, secretos, datos del reto ni archivos de configuración reales.

La primera escritura del README fue rechazada por GitHub: 403 Resource not accessible by integration. La cuenta humana muestra permisos push, pero eso no garantiza acceso de la integración. El listado de instalaciones accesibles no mostró una instalación para la cuenta propietaria Anaa-K03. No se publicó ningún archivo. Configurar la integración GitHub en esa cuenta y habilitar agentes con acceso de escritura, o revisar/reconectar la autorización existente. No compartir tokens ni contraseñas. Después se puede repetir la carga preparada sin rehacer investigación. Para obtener el kit, clonar o descargar ZIP de este repositorio conservando `.agents/skills/`.

Durante el evento, publicar código o telemetría reservada de Copa necesita el permiso aplicable. Esta autorización para publicar el kit no autoriza a subir futuros secretos o materiales reservados de la competición. Si se desea restringir el acceso más adelante, la propietaria puede cambiar la visibilidad desde Settings.
